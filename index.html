02

ตัวแปร & ชนิดข้อมูล

local, dynamic typing และชนิดข้อมูลทั้ง 8

พื้นฐาน▼
  • ประกาศด้วย local เสมอถ้าเป็นไปได้
  • ไม่ต้องบอกชนิดข้อมูล (dynamic typing)
  • 8 ชนิด: nil, boolean, number, string, function, table, userdata, thread
  • ตัวแปรที่ยังไม่มีค่า = nil
types.lua
local name    = "Lua"        -- string
local version = 5.4          -- number
local isFast  = true         -- boolean
local nothing = nil          -- nil

print(type(name), type(version), type(isFast), type(nothing))
print(type(print))   -- แม้แต่ print ก็เป็นค่าค่าหนึ่ง (function)!
string number boolean nil function

💡 ไม่ใส่ local ตัวแปรจะกลายเป็น "ตัวแปรโลก" (global) ซึ่งหาบั๊กยากและทำงานช้ากว่า — ติดนิสัยใส่ local ไว้เสมอ

03

เงื่อนไข & ตัวดำเนินการ

if / elseif / else และกับดักความจริงของ Lua

พื้นฐาน▼
  • "ไม่เท่ากับ" ใช้ ~= ไม่ใช่ !=
  • ทุกบล็อกจบด้วย end
  • มีแค่ nil กับ false ที่ถือว่าเป็นเท็จ
  • 0 และ "" เป็นจริง! ต่างจากหลายภาษา
grade.lua
local score = 75

if score >= 80 then
    print("เกรด A ยอดเยี่ยม!")
elseif score >= 60 then
    print("ผ่าน")
else
    print("สอบใหม่นะ")
end

-- เทคนิคสามทาง (ternary): a and b or c
local status = score >= 60 and "สอบผ่าน" or "สอบตก"
print(status)
ผ่าน สอบผ่าน

⚠️ ระวัง: แพตเทิร์น a and b or c จะพลาดถ้า b เป็น false/nil เพราะมันจะกระโดดไปคืนค่า c แทน

04

ลูปทั้ง 4 แบบ

while, repeat–until, numeric for และ generic for

พื้นฐาน▼
  • for i = เริ่ม, จบ, ก้าว
  • repeat..until ทำงานอย่างน้อย 1 รอบเสมอ
  • ipairs วนตามลำดับ · pairs วนทุกคีย์
  • ออกกลางทางด้วย break
loops.lua
for i = 1, 5 do
    print("รอบที่", i)
end

local fruits = {"มะม่วง", "มังคุด", "ทุเรียน"}
for index, value in ipairs(fruits) do
    print(index, value)
end

local n = 0
repeat
    n = n + 1
until n >= 3
print("สรุปค่า n =", n)
รอบที่ 1 ... รอบที่ 5 1 มะม่วง 2 มังคุด 3 ทุเรียน สรุปค่า n = 3

💡 Lua ไม่มี do-while และไม่มีลูปแบบ continue ในเวอร์ชันมาตรฐาน (Luau ของ Roblox มี continue)

05

ฟังก์ชัน

คืนค่าหลายค่า, พารามิเตอร์ไม่จำกัด และ closure

ระดับกลาง▼
  • คืนค่าได้หลายค่าพร้อมกันด้วย return a, b
  • ฟังก์ชันเป็น "ค่า" ชนิดหนึ่ง ส่งต่อ เก็บใส่ตัวแปรได้
  • ... รับอาร์กิวเมนต์ไม่จำกัดจำนวน
  • closure = ฟังก์ชันที่จำตัวแปรจากสภาพแวดล้อมที่สร้างมัน
functions.lua
-- คืนค่าสองอย่างพร้อมกัน
local function stat(min, max)
    return (min + max) / 2, max - min
end
local avg, range = stat(10, 20)
print("ค่าเฉลี่ย:", avg, "พิสัย:", range)

-- closure: ตัวนับที่จำค่าของตัวเองได้
local function counter()
    local n = 0
    return function()
        n = n + 1
        return n
    end
end
local tick = counter()
print(tick(), tick(), tick())   --> 1  2  3
ค่าเฉลี่ย: 15 พิสัย: 10 1 2 3

💡 ค่าตั้งต้นแบบง่าย: local function greet(name) return "หวัดดี " .. (name or "เพื่อน") end

06

สตริง & แพตเทิร์น

จัดการข้อความและค้นหาด้วย Lua patterns

ระดับกลาง▼
  • ต่อสตริงด้วย .. · ความยาวด้วย #s
  • สตริงยาวหลายบรรทัด: [[ ... ]]
  • Lua ใช้ "แพตเทิร์น" ของตัวเอง ไม่ใช่ regex
  • เรียกแบบเมธอดได้: s:upper()
strings.lua
local s = "lua สนุกจริง"
print(#s, string.upper(s), string.rep("ha", 3))
print(string.format("เวอร์ชัน %.1f เท่มาก", 5.4))

-- ดึงชื่อผู้ใช้กับโดเมนจากอีเมล
local email = "somchai@mail.com"
local user, domain = email:match("(%w+)@(%w+%.%w+)")
print(user, domain)
13 LUA สนุกจริง hahaha เวอร์ชัน 5.4 เท่มาก somchai mail.com

💡 %w = ตัวอักษร/เลข, %d = เลข, ( ) = วงเล็บจับค่า (ดูชีตหัวข้อแพตเทิร์นประกอบ)

07

Tables — หัวใจของ Lua

อาร์เรย์, ดิกชันนารี และทุกอย่างในก้อนเดียว

ระดับกลาง▼
  • table คือโครงสร้างข้อมูลชนิดเดียวของ Lua
  • ดัชนีอาร์เรย์เริ่มที่ 1 ไม่ใช่ 0!
  • เข้าได้ถึงทั้ง t.name และ t["name"]
  • เครื่องมือครบ: table.insert / remove / sort / concat
tables.lua
local player = {
    name  = "สมชาย",
    hp    = 100,
    items = {"ดาบ", "โล่"},
}

print(player.name, player["hp"], #player.items)

table.insert(player.items, "ยาฟื้นพลัง")
table.sort(player.items)
print(table.concat(player.items, " + "))

for key, value in pairs(player) do
    print(key, "=", value)
end
สมชาย 100 2 ดาบ + โล่ + ยาฟื้นพลัง (และคู่คีย์/ค่าทั้งหมดจาก pairs)

💡 ลบข้อมูลในอาร์เรย์ใช้ table.remove(t, i) อย่าใช้ t[i] = nil กลางรายการ เพราะจะทำให้รูโหว่ในลำดับ

Metatables & การเขียน OOP

เนรมิตคลาสและโอเปอเรเตอร์เองได้

ขั้นสูง▼
  • metatable = table พิเศษที่ควบคุมพฤติกรรมของอีก table
  • __index คือกลไกการสืบทอด / ค่าตั้งต้น
  • __add, __tostring ฯลฯ กำหนดพฤติกรรมโอเปอเรเตอร์
  • : (colon) แอบส่ง self ให้อัตโนมัติ
animal.lua
local Animal = {}
Animal.__index = Animal

function Animal.new(name, sound)
    return setmetatable({ name = name, sound = sound }, Animal)
end

function Animal:speak()          -- self ถูกส่งมาให้อัตโนมัติ
    return self.name .. " ร้อง " .. self.sound
end

local cat = Animal.new("แมว", "เมี๊ยว~")
local dog = Animal.new("หมา", "โฮ่ง!")
print(cat:speak())
print(dog:speak())
แมว ร้อง เมี๊ยว~ หมา ร้อง โฮ่ง!

💡 นี่คือแพตเทิร์น OOP มาตรฐานของ Lua — ไม่มี class ให้ใช้ แต่ metatable ทำได้ทุกอย่างที่ class ทำได้

Modules & require

แยกโค้ดเป็นไฟล์และใช้งานซ้ำอย่างมืออาชีพ

ระดับกลาง▼
  • โมดูล = ไฟล์ที่ return table (หรือค่าใด ๆ)
  • require จะโหลดไฟล์แค่ครั้งเดียวแล้วจำผลลัพธ์ไว้
  • ค้นหาไฟล์ตาม package.path
  • นิยมตั้งชื่อไฟล์ให้ตรงกับชื่อตัวแปรที่รับ
greet.lua + main.lua
-- ===== greet.lua =====
local M = {}
function M.hello(name)
    return "หวัดดี " .. name .. "!"
end
return M

-- ===== main.lua =====
local greet = require("greet")
print(greet.hello("โลก"))
หวัดดี โลก!

💡 อยากจัดกลุ่มไฟล์? ใช้จุด: require("utils.math") จะมองหาไฟล์ utils/math.lua

10

จัดการข้อผิดพลาด

error, pcall และ xpcall

ระดับกลาง▼
  • error("ข้อความ") เหวี่ยงข้อผิดพลาด
  • pcall(fn) รันฟังก์ชันแบบกันโปรแกรมพัง
  • คืนค่า true, ผลลัพธ์ หรือ false, ข้อความผิดพลาด
  • assert ตรวจสอบเงื่อนไขก่อนทำงานต่อ
errors.lua
local function readFile(path)
    if path == nil then
        error("ต้องระบุชื่อไฟล์!")
    end
    return "เนื้อหาใน " .. path
end

local ok, result = pcall(readFile, nil)
if not ok then
    print("จับผิดได้:", result)
else
    print(result)
end
จับผิดได้: errors.lua:3: ต้องระบุชื่อไฟล์!

💡 xpcall(fn, handler) เหมือน pcall แต่ให้ฟังก์ชันจัดการข้อผิดพลาดแนบไปด้วย เหมาะกับการเก็บ log

11

Coroutines

หยุด–ทำงานต่อได้ สู่การทำงานแบบร่วมมือกัน

ขั้นสูง▼
  • สร้างด้วย coroutine.create(fn)
  • resume เริ่ม/ทำต่อ · yield หยุดชั่วคราว
  • สถานะ: suspended / running / dead
  • ต่างจาก thread: coroutine ไม่ทำงานขนานเอง ต้องสลับเอง
coro.lua
local producer = coroutine.create(function()
    for i = 1, 3 do
        print("ผลิตค่า:", i)
        coroutine.yield(i * 10)    -- หยุดและส่งค่าออกไป
    end
end)

print(coroutine.resume(producer))  -- ผลิตค่า: 1
print(coroutine.resume(producer))  -- ผลิตค่า: 2
print(coroutine.status(producer))  -- suspended
ผลิตค่า: 1 true 10 ผลิตค่า: 2 true 20 suspended

💡 ใช้ coroutine ทำ generator, state machine ของเกม หรือระบบหน่วงเวลาแบบเฟรมต่อเฟรมได้สวยงามมาก

ไฟล์ I/O & โลกจริง

อ่านเขียนไฟล์ และก้าวสู่โปรเจกต์จริง

ขั้นสูง▼
  • io.open(path, mode) — "r" อ่าน, "w" เขียนทับ, "a" เติม
  • อ่านทั้งไฟล์ด้วย :read("*a")
  • ปิดไฟล์ด้วย :close() ทุกครั้ง
  • จากนี้เลือกสายได้เลย: เกม / ปลั๊กอิน / เซิร์ฟเวอร์
files.lua
-- เขียนไฟล์
local out = assert(io.open("save.txt", "w"))
out:write("เซฟเกม: ด่าน 7, เหรียญ 999")
out:close()

-- อ่านกลับ
local inn = assert(io.open("save.txt", "r"))
print(inn:read("*a"))
inn:close()
เซฟเกม: ด่าน 7, เหรียญ 999

ร่างที่ 4 — ซ้อนกัน

table ซ้อน table สร้างโครงสร้างซับซ้อนได้ไม่จำกัดชั้น

array.lua
local scores = {95, 78, 88, 100}
print(scores[1], scores[4])   --> 95  100
print("จำนวน:", #scores)      --> 4
table.insert(scores, 60)      -- เพิ่มท้าย
table.remove(scores, 2)       -- ลบตัวที่ 2
table.sort(scores)            -- เรียงน้อยไปมาก
dict.lua
local config = {
    theme    = "dark",
    fps      = 60,
    fullscreen = false,
}
config.volume = 80                 -- เพิ่มคีย์ใหม่
config.theme  = nil                -- ลบคีย์ด้วยค่า nil
print(config.fps, config.volume)   --> 60  80
object.lua
local sword = {
    name   = "ดาบจันทรา",
    damage = 25,
    hit = function(self, enemy)
        enemy.hp = enemy.hp - self.damage
    end,
}
local slime = { hp = 40 }
sword:hit(slime)
print("เลือดสไลม์เหลือ:", slime.hp)   --> 15
nested.lua
local world = {
    zones = {
        { name = "ป่าเริ่มต้น", monsters = {"สไลม์", "ค้างคาว"} },
        { name = "ถ้ำมืด",     monsters = {"โกเลม"} },
    },
}
print(world.zones[1].monsters[2])   --> ค้างคาว
for _, z in ipairs(world.zones) do
    print(z.name, "มีมอนสเตอร์", #z.monsters, "ชนิด")
end

Cheat Sheet — เปิดดูได้ทุกเมื่อ

คำสั่งหน้าที่
#sความยาวของสตริง
s:upper() / s:lower()แปลงเป็นตัวพิมพ์ใหญ่ / เล็ก
s:sub(i, j)ตัดสตริงตำแหน่งที่ i ถึง j (ติดลบคือนับจากท้าย)
s:rep(n)ทำซ้ำ n รอบ
s:reverse()กลับหลัง
s:find(แพตเทิร์น)หาตำแหน่งที่เจอ (เริ่ม, จบ)
s:match(แพตเทิร์น)ดึงค่าที่ตรงกับวงเล็บจับ
s:gsub(แพตเทิร์น, แทนที่)แทนที่ทุกจุดที่เจอ
s:gmatch(แพตเทิร์น)วนทุกจุดที่เจอ
string.format(fmt, ...)จัดรูปแบบ เช่น "%s มี %d คะแนน"
a .. bต่อสตริงเข้าด้วยกัน
คำสั่งหน้าที่
#tจำนวนสมาชิกในส่วนอาร์เรย์
table.insert(t, ค่า)เพิ่มต่อท้าย
table.insert(t, i, ค่า)แทรกที่ตำแหน่ง i
table.remove(t, i)ลบตำแหน่งที่ i (คืนค่าที่ลบ)
table.concat(t, คั่น)รวมสมาชิกเป็นสตริง
table.sort(t)เรียงน้อยไปมาก
table.sort(t, function(a,b) return a > b end)เรียงมากไปน้อย
ipairs(t)วนตามลำดับ 1, 2, 3, …
pairs(t)วนทุกคีย์ (ลำดับไม่การันตี)
คำสั่งหน้าที่
math.floor(x)ปัดลง
math.ceil(x)ปัดขึ้น
math.abs(x)ค่าสัมบูรณ์
math.sqrt(x)รากที่สอง
math.max(...) / math.min(...)ค่ามากสุด / น้อยสุด
math.random()สุ่มทศนิยม 0–1
math.random(n)สุ่มจำนวนเต็ม 1 ถึง n
math.random(a, b)สุ่มจำนวนเต็ม a ถึง b
math.pi / math.hugeค่าพาย / อนันต์
x % yเศษจากการหาร
x ^ yยกกำลัง
สัญลักษณ์ความหมาย
%a %d %w %s %pตัวอักษร / เลข / ตัวอักษร+เลข / ช่องว่าง / เครื่องหมาย
.อักขระใดก็ได้ 1 ตัว

// 07 · ทดสอบตัวเอง

ควิซ 6 ข้อ — วัดระดับจันทราของคุณ

ความคืบหน้า
0/6

Q1ผลลัพธ์ของ print(10 .. 20) คืออะไร?

✔ ถูกแล้ว! ตัวดำเนินการ .. คือการต่อสตริง — เลขจะถูกแปลงเป็น "10" และ "20" แล้วต่อกันเป็น "1020" ส่วนการบวกต้องใช้ +

Q2สมาชิกตัวแรกของ table ใน Lua อยู่ที่ดัชนีเท่าไร?

✔ ถูกต้อง! อาร์เรย์ของ Lua นับเริ่มที่ 1 เสมอ — นี่คือจุดที่คนมาจากภาษาอื่นพลาดบ่อยที่สุด

Q3ตัวแปรที่ยังไม่เคยถูกกำหนดค่า จะมีค่าเป็นอะไร?

✔ ใช่แล้ว! nil คือตัวแทนของ "ไม่มีค่า" และการกำหนด x = nil ก็เท่ากับการลบตัวแปรนั้น

Q4ตัวดำเนินการ ~= ใน Lua หมายความว่าอะไร?

✔ ถูกต้อง! ~= คือ "ไม่เท่ากับ" — ส่วนการตรวจสอบเท่ากันใช้ == (Lua ไม่มี !=)

Q5ค่าใดต่อไปนี้ถือว่า "เป็นจริง" ในเงื่อนไขของ Lua?

✔ เก่งมาก! มีเพียง nil และ false เท่านั้นที่เป็นเท็จ — แม้แต่ 0 และสตริงว่างก็เป็นจริงใน Lua

Q6pcall(fn) คืนค่าอะไรเมื่อ fn ทำงานสำเร็จ?

✔ ถูกต้อง! สำเร็จ → true, ผลลัพธ์ · ล้มเหลว → false, ข้อความผิดพลาด จึงนิยมเขียน local ok, err = pcall(...)

สงสัยตรงไหน อ่านตรงนี้ก่อน

Lua ยากไหมสำหรับมือใหม่ที่เพิ่งเริ่มเขียนโค้ด?+

ไม่ยากเลยครับ Lua เป็นหนึ่งในภาษาที่เหมาะกับมือใหม่มากที่สุด ไวยากรณ์มีไม่กี่อย่าง ไม่มีเครื่องหมายจุกจิก อ่านโค้ดออกได้ภายในวันเดียว และหลักสูตรนี้ก็ออกแบบมาสำหรับคนเริ่มจากศูนย์โดยเฉพาะ

ต้องเรียนภาษาอื่นมาก่อนไหม?+

ไม่จำเป็นเลย เรียน Lua เป็นภาษาแรกได้เลย แต่ถ้าคุณเคยเขียน Python หรือ JavaScript มาก่อน จะยิ่งเข้าใจคอนเซ็ปต์อย่าง closure และ table ได้เร็วขึ้นไปอีก

Lua ต่างจาก Python อย่างไร?+

Python เด่นเรื่องไลบรารีมหาศาลและงานด้านข้อมูล ส่วน Lua เด่นเรื่องความเล็ก ความเร็ว และการฝังเข้าไปในโปรแกรมอื่น ทั้งคู่เป็นมิตรกับมือใหม่ หลายคนเรียนทั้งคู่แล้วใช้ให้ถูกงาน

ควรใช้ Lua เวอร์ชันไหนดี?+

ถ้าเรียนทั่วไปใช้ Lua 5.4 (ล่าสุด) · ถ้าจะทำเกม Roblox ระบบจะติดตั้ง Luau ให้อัตโนมัติ · ถ้าเขียนปลั๊กอิน Neovim หรือสคริปต์ Redis จะเป็น Lua 5.1 / LuaJIT — พื้นฐานเหมือนกันหมด เรียนครั้งเดียวใช้ได้เลย

ใช้เวลากี่สัปดาห์ถึงจะเขียนโปรเจกต์จริงได้?+

ถ้าทำตามเส้นทาง 4 ระยะของเว็บนี้ วันละประมาณ 30–60 นาที ภายใน 4–6 สัปดาห์คุณจะสามารถเขียนเกมเล็ก ๆ ด้วย LÖVE หรือปลั๊กอินแรกของคุณเองได้อย่างสบาย ๆ
